# 3-minute demo

1. Open the dashboard.
2. Submit a payment-api 502 incident.
3. Click Investigate.
4. Show historical local matches.
5. Start Hindsight and retain a previous resolution.
6. Investigate a similar incident again.
7. Show Hindsight recall in the response.
8. Click Resolve & Remember.
9. Explain the loop: Remember -> Recall -> Recommend -> Resolve -> Remember.
